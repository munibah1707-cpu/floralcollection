# 🧕 Floral Collection

A beautiful, modern, and fully responsive e-commerce website designed for a premium hijab and modest fashion brand. This project features a complete shopping flow from product browsing to order placement.

🚀 **[Click Here to View the Live Demo](https://floralcollection.netlify.app)**

---

## ✨ Features I Added

*   **Shopping Cart System:** A slide-out cart drawer where users can add items, change quantities, and see their real-time total.
*   **Order System:** A checkout form modal where customers can complete their orders and choose to send them directly via **WhatsApp** or **Email**.
*   **Login & Sign In System:** Interactive user authentication modals for a complete account layout experience.
*   **Responsive Design:** Fully optimized with smooth custom animations for mobile, tablet, and desktop viewports.
*   **Product Enhancements:** Includes an animated search bar, interactive color swatches, and a custom product visual gallery.

---

## 🛠️ Tech Stack

*   **HTML5:** Page structure and semantic layout.
*   **Custom CSS3:** Pure styling, layout design, and animations (built from scratch without frameworks).
*   **JavaScript (ES6+):** For the interactive cart logic, popup models, and state toggles.
*   **Netlify:** For hosting and live continuous deployment.
